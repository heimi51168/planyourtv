# PlanYourTV 常见问题

PlanYourTV（计划电视）是一个开源的 **Android TV 儿童时间管理桌面**，基于 Aerial 1.85（MIT）。它替换电视自带桌面，把使用时段、每日额度、单次上限、休息、可看的 App、学习模式和答题解锁变成电视自己执行的规则。

- 项目主页：https://github.com/heimi51168/planyourtv
- 官方下载：https://planyourtv.me/download/
- 安装文档：[INSTALL.md](INSTALL.md)
- 给 AI 助手的安装说明：[AGENT-INSTALL.md](AGENT-INSTALL.md)
- 当前社区源码版本：`1.85.006` / 116006

## 产品与定位

### PlanYourTV 是什么？

一个桌面级的 Android TV 儿童时间管理 App。它不是一个普通的定时器，也不是监控软件：它接管电视桌面，按家长设置的规则决定什么时候能看、看多久、能看哪些 App。时间用完时，孩子可以完成一轮答题来赚取额外观看时间。

### 它和普通「儿童锁」或「屏幕时间」有什么不同？

普通儿童锁通常是系统里的一个开关，孩子退出受限 App 就可能绕过；PlanYourTV 是桌面本身，开机和按 Home 都回到它。除了时段和时长，它还支持 App 级白名单、学习 App 免计时、学习模式、答题奖励、题库与错题管理，以及电视端和局域网手机设置页。

### 和 Aerial 是什么关系？

PlanYourTV 是基于 [Aerial](https://github.com/pengchujin/aerial-tv)（MIT）的独立项目，保留了 Aerial 的桌面、设备适配和 Home Guard。它增加了儿童时间管理、学习模式、答题、题库和家长控制。它不是 Aerial 官方项目，也不代表 Aerial 上游。设备兼容范围与 Aerial 保持一致；详见 [README 的兼容性说明](../README.md#兼容性与-aerial-保持一致)。

### 免费吗？开源吗？

免费，源码以 MIT 许可证发布。你可以自己编译、修改和分发；修改后请保留 Aerial 和第三方的版权声明。

### 为什么叫「桌面级」？

因为它替换的是电视桌面，而不是在某个 App 里加一个计时器。开机、按 Home、从其他 App 返回，都会回到 PlanYourTV；计时会话期间，打开家长没选的 App 会被拦回桌面。它是家长控制的辅助工具，不是防止设备所有者或拥有 ADB 权限的人绕过的安全边界。

### 远程管理为什么找不到？

远程管理目前是路线图功能，社区构建默认关闭并隐藏入口。本地规则、学习模式、计时和答题不依赖它，功能完整。远程服务端和手机家长端源码不在本仓库。

## 功能

### 可以限制哪些 App？

家长在家长中心勾选可以看的**娱乐 App**。计时会话期间，打开其他 App 会被 Home Guard 拦回 PlanYourTV。计时只针对家长选定的娱乐 App；不需要为了管控去卸载系统应用，也不建议停用电视自带桌面。

### 学习 App 会计时吗？

不会。学习 App 是单独的分组，**不计时、不占每日额度**；孩子从锁屏进入学习模式后使用，学习模式期间只显示学习 App。娱乐 App 和学习 App 可以由家长分别勾选。

### 学习模式需要 PIN 吗？

不需要。进入学习模式后，电视只显示家长勾选的学习 App，其他 App 隐藏；学习模式不计时、不扣额度。退出学习模式会回到锁屏，不会自动开始新的计时。待机或关机后学习模式自动退出。

### 时段、每日额度、单次上限和休息怎么配合？

家长可以分别为工作日和周末设置每天可用的时间段。在可用时段内：

- 每次连续观看不超过**单次上限**；
- 每天累计不超过**每日额度**；
- 一次会话结束后，按设置的**休息间隔**等待，才能开始下一次；
- 时段之外电视保持锁定。

具体默认值以电视上的家长中心为准，可以修改。

### 单次计时可以设多久？

家长可以在锁屏或家长中心手动开始一段 **5–120 分钟**的观看时间，默认 20 分钟，5 分钟一档。适合周末临时加时，或家长主动让孩子看一会儿。

### 答题怎么奖励？

时间用完后，锁屏会出现答题挑战。完成整轮题目后结算：答对达到门槛，就按「答对题数 × 每题奖励分钟」计算奖励，并受单次奖励上限约束；奖励时长进入下一次观看。默认 5 道题，答对至少 1 道才有奖励。题数（1–10）、答对门槛、每题奖励分钟数和奖励上限都可以在手机设置页调整。

### 答错会怎样？

每道题作答后都会立即显示对错和解析；全部题目答完后统一结算。答错不会加时，但可以看到解析，下一轮还有机会。答题不是惩罚，而是给孩子一个自己挣时间的出口。

### 题目从哪里来？

有三种来源：

1. **内置题库**：120 道小学题，1–6 年级，语文、数学、英语、科学各 30 道，开箱即用。
2. **手动出题**：家长在手机设置页自己添加选择题。
3. **AI 批量出题**：家长配置自己的 OpenAI 兼容模型服务，由 AI 按学科、年级、难度和数量生成题目；家长勾选后发送到电视题库。

### AI 出题是本地大模型吗？

不是。PlanYourTV 不在电视上运行大模型。AI 出题由家长配置的 **OpenAI 兼容模型服务**提供（默认 DeepSeek 接口），电视作为代理把出题要求发给该服务，再把生成的题目保存到电视。没有配置 AI 时，内置题库和手动出题完全可用。

### AI 出题要去 DeepSeek 获取 Key 吗？怎么设置？

要，但这是**可选的**。AI 出题使用家长自己的模型账号，PlanYourTV 不附带、也不共享 API Key。以默认的 DeepSeek 为例：

1. 家长在电脑或手机上打开 [DeepSeek 开放平台](https://platform.deepseek.com)，注册并创建 API Key（费用和额度由家长与 DeepSeek 结算）。
2. 手机和电视连同一个 Wi-Fi，打开电视家长设置页的 **AI 出题**。
3. 模型服务地址保持 `https://api.deepseek.com`，模型名按 DeepSeek 文档填写；粘贴 API Key，点 **测试连接**，成功后保存。
4. 第一次生成前需要勾选同意，把出题要求（学科、年级、难度、数量等）发送给该服务。

也可以换成其他 OpenAI 兼容服务，填对应的 HTTPS 地址、模型名和 Key。密钥只保存在电视本地，不回传给手机页面；不要把 Key 交给安装用的 AI 助手，也不要贴进公开 issue。

### API Key 安全吗？

API Key 保存在电视端（系统支持时加密），不回传给手机页面，也不保存到本产品的云端；生成题目时只随请求发送给家长配置的模型服务商。请求只包含学科、年级、难度、数量等出题参数，不包含家庭信息。家长应使用自己信任的模型服务，并定期轮换 Key。

### 题库和错题怎么管理？

手机设置页可以查看未使用、已回答、本轮中、答对、答错、旧记录和过期题目，支持去重、容量管理和批量清理。错题本会把最近答错的题排在前面，显示答错次数和作答日期；可以单独清空错题，保留其他题目。

### 支持几台电视？

每台电视独立安装、独立保存规则和题库。社区版本不要求账号，也不在云端合并多台电视的数据。多台电视需要分别设置。

## 安装与兼容

### 需要 root 吗？

不需要。安装和授权通过电脑 ADB 完成，电视不需要 root。安装后日常使用也不需要一直连着电脑。

### 支持哪些电视？

Android TV 5.0+（API 21+）。设备兼容范围与 Aerial 保持一致；Aerial 支持的小米、TCL、索尼、海信、创维等 Android TV 通常也可以运行。**本项目只对小米电视 `standard` 版本做过真机验证**，其他机型和 `guard` 版本沿用 Aerial 上游的支持范围，未逐一验证。

Android 4.x、LG webOS、三星 Tizen、鸿蒙智慧屏不是本项目的目标平台，不支持。社区源码快照也不包含 Android 4.x 的 Aerial Lite。

### 小米电视怎么安装？

1. 在电视上打开开发者模式和 ADB 调试。
2. 电脑安装 Android platform-tools，运行 `adb connect <电视IP>:5555`。
3. 下载官方 [planyourtv-standard.apk](https://planyourtv.me/download/planyourtv-standard.apk)。
4. 运行 `adb install -r planyourtv-standard.apk`。
5. 按 [INSTALL.md](INSTALL.md) 授予权限，按 Home 选择 PlanYourTV。

更省事的办法是把 [README 里的提示词](../README.md#让-ai-帮你安装) 整段复制给豆包电脑版等能执行命令的 AI 助手。

### TCL / 雷鸟怎么安装？

TCL 电视一般也能用 ADB 安装；部分固件会拒绝声明了桌面 Activity 的包，这时改用 [planyourtv-guard.apk](https://planyourtv.me/download/planyourtv-guard.apk)，由 Home Guard 通过无障碍服务接管 Home。部分 TCL / 雷鸟固件还需要在电视管家、自启动或安全设置里允许 PlanYourTV。具体步骤见 [INSTALL.md](INSTALL.md)。

### 没有 ADB 能安装吗？

不能完成完整安装。PlanYourTV 需要 ADB 授予无障碍、通知监听、安全设置等权限；这些权限无法只靠电视遥控器全部打开。打不开 ADB 的机型请先确认电视是否支持，不要安装第三方 ADB 开启器。

### 装哪个 APK？

先装 `standard`。如果固件拒绝安装桌面类 App，或提示不允许安装 Home Activity，再试 `guard`。两个版本都只从官方下载页获取：

- [planyourtv-standard.apk](https://planyourtv.me/download/planyourtv-standard.apk)
- [planyourtv-guard.apk](https://planyourtv.me/download/planyourtv-guard.apk)

### 会替换原桌面吗？能恢复吗？

`standard` 会声明为 Home App，按 Home 时可以选择 PlanYourTV。PlanYourTV **不会卸载或停用电视自带桌面**；随时可以把默认桌面切回原桌面，再卸载 PlanYourTV。`guard` 版本不声明 Home Activity，而是通过无障碍服务接管 Home，适合拒绝第三方桌面的固件。

### 安装后很卡怎么办？

确认安装的是 release APK，而不是 debug 包；然后运行：

```bash
adb shell cmd package compile -m speed -f com.planyourtv.tv
```

电视第一次安装后可能需要预编译。debug 包在电视上会明显更卡，不适合日常使用。

### 安装提示签名不一致怎么办？

说明电视上已有同包名但不同签名的 PlanYourTV。**不要直接卸载**：卸载会删除规则、题库、壁纸和照片。先确认是否接受数据丢失；接受后再运行 `adb uninstall com.planyourtv.tv`，然后重新安装官方 APK。覆盖升级应使用同一个签名来源。

## 隐私与安全

### 会上传我的数据吗？

本地模式不需要账号，不上传规则、App 列表或答题记录。可选网络请求只有：检查更新、天气、必应每日壁纸，以及同一局域网内的手机设置页。使用 AI 出题时，出题要求会发送给家长自己配置的模型服务商，请求不包含家庭信息。详见 [PRIVACY.md](../PRIVACY.md)。

### 有广告或统计 SDK 吗？

社区源码不包含广告、行为统计或崩溃上报 SDK。

### 孩子能绕过吗？

它能拦住日常的「退出 App、按 Home、换 App」，但**不是防破解系统**。拥有 ADB、root 或设备所有者权限的人仍然可以绕过；孩子也可能通过关机、断网或恢复出厂设置绕过。请把它当作规则执行工具，并保管好家长 PIN 和恢复码。

### 默认 PIN 是多少？

默认 PIN 是 `123456`。首次安装后请立即在家长中心修改。`123456` 和 `666666` 会被视为默认值并显示风险提示。

### 恢复码丢了怎么办？

首次开启家长模式时会生成一次性恢复码，请拍照保存。恢复码丢失后无法自助重置 PIN，只能卸载重装，数据会丢失。

### 无线 ADB 要一直开吗？

不需要。安装、授权和调试完成后应关闭无线 ADB，至少不要把它暴露到公网。保持 5555 端口开放会带来安全风险。

## 使用与维护

### 手机设置页怎么打开？

电视上运行 PlanYourTV 时，在电视端打开手机设置页的二维码；手机和电视连接同一个 Wi-Fi，扫码即可。页面只在局域网内提供服务，不需要账号，也不经过公网。页面不能解锁电视。

### 支持哪些语言？

界面支持简体中文、英语、俄语、乌克兰语和哈萨克语。手机设置页同样支持这五种语言。

### 怎么升级？

电视上出现「有新版本」时，按提示下载并安装；设置和题库会保留。也可以重新下载官方 APK 覆盖安装。不要从非官方地址下载 APK。

### 怎么卸载？

先把默认桌面切回电视自带桌面，再运行：

```bash
adb shell am force-stop com.planyourtv.tv
adb shell pm uninstall com.planyourtv.tv
```

卸载会删除本机规则、题库、壁纸和照片。不要卸载或停用电视自带桌面；不要删除其他无障碍或通知监听服务。

### 支持投影仪和电视盒子吗？

只要设备运行 Android TV 5.0+，并且能通过 ADB 安装，原则上可以尝试；实际兼容范围与 Aerial 保持一致。部分投影仪和盒子固件会限制第三方桌面或无障碍服务，能否作为默认桌面取决于固件。请先用 [INSTALL.md](INSTALL.md) 检查，并在真机上验证。

### 支持 LG webOS、三星 Tizen 或鸿蒙智慧屏吗？

不支持。这些不是 Android TV 系统，无法安装 Android APK。
